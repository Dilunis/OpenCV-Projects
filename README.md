
# OpenCV Beginner Projects

A collection of beginner-friendly Computer Vision projects
developed using Python, OpenCV, NumPy, and Matplotlib in Google Colab.

## Projects

1. Colour Detection
2. Edge Detection
3. Contour Detection
4. Object Counting
5. Object Area Measurement
6. Face Detection
7. Coin Detection and Counting

## Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Google Colab

## Goal

To learn fundamental computer vision techniques through
practical image processing projects.
